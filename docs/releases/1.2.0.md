# Wisp 1.2.0

Wisp 1.2.0 is faster, safer and better at picking the right tool.

- **Faster local inference.** Checking that the local engine is the qualified oMLX server now takes about half the time with identical checks, and a turn asks the engine which model is resident once instead of before every step. A simple greeting makes two engine calls instead of three.
- **Better tool routing.** Routing was measured against a 361-prompt corpus and fixed where it failed (64% to 82%): fewer send or delete tools offered when you did not ask for them, "sure" no longer reaches the model with no tools, "any new emails?" reads your mail instead of searching the web, and common typos route correctly without ever rewriting a recipient or file name.
- **Local apps can use tools.** Ollama, LM Studio, llama.cpp and MTPLX can drive Agent and Coding work after Wisp verifies their context window and tool calling, with a Test Tool Calling check in Settings.
- **Plan tomorrow in Wisp Today.** Study slots and agendas respect the selected day. A preparation reminder needs a dated confirmation and is reported as created only after a verified success receipt.
- **Find the right note and reminder.** Topic lookups require the words you used and say how fresh the data is; undated Apple reminders are listed; long-overdue Wisp-only records stop looking current.
- **Readable inbox and summaries.** The inbox digest is sorted by what needs attention; mail from people is separated from newsletters; mail history reads from Mail's local index.
- **Easier notch.** The top edge of the screen and most of the notch open the menu.
- **Troubleshoot locally.** Review a problem report with request stages and timing. Detailed content is optional, previewed, and redacted on a best-effort basis; nothing is uploaded automatically.
- **Safer by default.** Pasted API keys are redacted, approvals are strict and bound to the request that asked, launch never terminates programs Wisp does not own, protected paths cover every path argument, and "Always allow" can no longer lift tools that must confirm every time.

The download is for Apple Silicon Macs running macOS 14 or newer. Wisp requires a separately installed oMLX server and models. The app is ad-hoc signed, so macOS may ask you to grant Calendar, Reminders and Full Disk access again.

Publication is gated on live-measured performance evidence for the exact release commit; checksums, provenance, dependency inventories and QA evidence are retained as build artifacts.
