# Wisp 1.2.0

Wisp 1.2.0 improves everyday planning, summaries, and troubleshooting.

- **Plan tomorrow in Wisp Today.** Ask for a study slot tomorrow; Wisp respects the selected day and avoids creating study reminders when there are no assignments to support them.
- **Find the right note.** Topic lookups require the requested words, refresh Notes before answering, and explain when a result comes from an older snapshot.
- **Read clearer daily summaries.** Mail from people is separated from newsletters and notifications, conversation coverage is clearer, and unavailable sources degrade to a readable fallback.
- **Keep reminders consistent.** Undated reminders survive synchronization, stale Wisp study reminders expire, and manually created reminders stay intact.
- **Troubleshoot locally.** Review a problem report with request stages and timing. Detailed content is optional, shown in a preview, and redacted on a best-effort basis. Wisp never uploads these reports automatically.
- **Reduce local engine verification overhead.** Runtime tree checks use a more efficient walk; independent checks run concurrently; executable paths use the native macOS inspection API. Ownership, signatures, paths, and connected sockets still have to qualify before request data is sent.
- **Make failures easier to understand.** Engine, memory, conversation-length, and confirmation-timeout failures have clearer explanations and next steps.

The download is for Apple Silicon Macs running macOS 14 or newer. Wisp requires a separately installed oMLX server and models.
