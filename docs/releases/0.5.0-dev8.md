**Wisp 0.5.0-dev8** is a development build for testers. It builds on [dev7](0.5.0-dev7.md), and everything those notes say still applies unless it's listed here.

## Fixes

- **Save power stays quiet when the engine can't lift a limit.** If Wisp's built-in engine doesn't answer, or refuses, when Wisp asks it to lift a power limit mid-reply, Wisp no longer asks again (and logs a warning) every second while that reply runs. It waits a minute before asking again, or stops for the rest of the run if the engine refused. No new limit is set in the meantime. Each ask also gives up sooner: it tries at most two connections, and none after one that timed out.
