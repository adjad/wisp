# 0.5.0 hand checks for Ask

These need a real Mac, the real model or a real send. Automated tests cover the rules behind them, but not the real model's answers or a real send. None of these checks was run when this list was written.

## Web questions on the first message of a new chat

Ask each in a new chat and check that the receipt shows a web search and the answer comes from it.

1. "Is Costco open on Sunday?"
2. "When does Trader Joe's close tonight?"
3. "What are Costco's hours?"
4. "Who is the president?" The answer must be current, not from the model's memory.
5. "What is the latest iPhone?"

Then ask "Is Mom's open on Sunday?" in a new chat. It must not search the web.

## After a send whose result is unknown

This state cannot be produced on demand any more. A forward used to cause it every time; now it only happens when Mail or Messages does not confirm a real send in time. The behaviour is covered by an automated test (`tests/test_model_led_full_routing.py`, `test_withheld_actions_are_explained_and_lifted_by_resolution`). If you do land in it:

1. Ask a read-only question such as "any email about enrollment?". The answer must come without the line "An earlier action in this chat may not have finished".
2. Ask "did it send?". The line must appear, and Wisp must not claim the send went through.
3. Ask for a new send in the same chat. The line must appear and nothing is sent.

## Forwarding through Apple Mail (switched off in this build)

As shipped, "forward that email to …" shows its card and then says nothing was sent and offers to send the text as a new email. To switch real forwarding on, all of these are needed, in order:

1. In `app/Sources/WispApp/OutboundSender.swift`, make `forwardEmail` use `MailActionScript.findInboxMessage(messageID:)` in place of `unverifiedForwardLookup`.
2. Set `APPLE_MAIL_FORWARD_READY = True` in `service/tools/action_tools.py`.
3. Build a preview (`./scripts/wisp-build preview`) and install it.
4. In Ask: "forward the latest email from <a sender> to <your own address>". Approve the card.
5. In Mail's Sent mailbox check: one message only, sent to your address, with the original email's text and attachments present.
6. Repeat with a note: "forward it to <your own address> and say FYI". Check that "FYI" is above the original and the original is still there. The reply script found that reading a new message's content can come back empty, which would send the note alone.
7. Repeat with an email that is in a second Mail account.
8. Only if 5 to 7 all pass, keep the two changes.

## Human-sounding replies

1. Turn on Settings › Human-sounding replies.
2. Ask "draft an email to <your own address> saying I'll be ten minutes late".
3. The draft's text may follow the style. Wisp's own sentence around it ("Here's a draft…") must read like its normal answers.
4. Ask "what's on my calendar today". The answer must not change style.
