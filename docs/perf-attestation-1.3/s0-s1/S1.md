## Values and caller obligations

The standalone module imports only `dataclasses`. `QualificationKey` contains all
exact design key dimensions; paths are literal and signing predicates must be
bound to the qualifier's rule revision. `ClockSample` supplies a domain, now and
prior reading. Absolute integer nanoseconds avoid nonfinite/fractional times;
negative or backwards samples reject. No real clock is selected or qualified.

`QualificationLease` binds original audit start/expiry, qualification ID, both
revocation generations, process lifetime, clock domain, caller-supplied complete
server/parent facts, boundary fingerprints and an opaque authority reference.
`BuildToken` binds key, process, global/key generations, policy, expected replacement
revision, nonce, initiating transport lifetime and absolute deadline.
`PublicationSnapshot` supplies immutable one-key metadata and admission flags; it
is not a store, lock, coherent real observation or worker accounting mechanism.

Records are frozen and slotted. Facts allow nonempty exact tuples recursively
containing exact strings, bytes, integers, booleans and None; mutable aliases,
subclasses and arbitrary objects reject. Comparisons also require scalar types
to agree, preventing `True == 1` fact aliasing. Frozen Python records do not isolate
hostile Python capable of deliberately bypassing freezing.

`lease_time_valid` enforces original `start <= now < expiry` in the same domain.
`lease_generation_current` is captured-generation revocation eligibility, including
for expired streams; replacement revision deliberately does not revoke a lease.
`lease_usable` adds valid time, admitted policy, manifest absence and no quarantine.
`token_owns_slot` compares the full token/current context and initiator's open
lifetime for completion, failure and timeout retirement. An expired current job
may still retire; stale jobs cannot affect successors. `publication_eligible` adds
a usable lease and strict build deadline. Changed server/parent facts or boundary
fingerprints cannot replace a same-generation published lease: revoke first, then
reserve a new token.

No predicate mutates anything or grants actual authority. Future callers must
serialize comparison/commit, maintain nonce and lifetime uniqueness/close
tombstones, account real workers, qualify actual fact completeness/truth and clock
support, capture audit start before the first input, and derive expiry from an
explicitly admitted hard duration. No production W or build timeout is chosen.
An authority ID never replaces qualification or authorizes credential emission.

with zero failures/errors/skips. Target runtime was 0.024 seconds; combined raw
output was 23,002 bytes. Existing Python 3.14.3 ran with `-I -S -B`; no third-party

The frozen private runner guards target imports/effects: no socket, subprocess,
ctypes, loop, thread/executor, full-service import, target write/mutation or read
outside exact source/test/runner plus interpreter stdlib. Its exec alarm caps the
single process at 120 seconds; output shares a 1 MiB budget. No guard was deliberately
invoked. Target created no files, sockets, workers, loops or children, requiring no
cleanup. Raw log includes actual imported file paths/hashes. Ordinary Python stdlib
native extensions are interpreter dependencies, not attestation qualification.
The guards defend this reviewed closure, not arbitrary hostile code.

`VALIDATION.json` pins source/test/interpreter/runner/freeze/log. No failures or
retries occurred. Static preservation checks and `git diff --check` passed. No
production import/call references the module. QA manifest registration adds exactly
one test-classification entry; its write window is closed. Full QA/legacy test
execution was not admitted locally.

| New controls | Design-derived expectation |
| --- | --- |
| Start, just before/at/after expiry, completion/use, late build, old/fresh lease | Strict original expiry, no refresh borrowing (F1/L1) |
| Domain/regression/invalid times, empty/reversed interval, huge integers | Coherent injected time; no real clock qualification |
| Every key dimension and literal path difference | No key alias normalization (F4) |
| Every token dimension and independent current-context mismatch | Full current ownership, not nonce/key alone (C1) |
| Deadline equality, retirement and initiator close | No late publication; current timeout retirement remains possible |
| Stale success/error, replacement nonce and successor survival | No stale successor publication/revocation (C1) |
| Changed facts/fingerprints, boolean/integer alias, stale published generation | Revoke before changed-incarnation replacement |
| Captured generations, replacement revision, expired stream | Replacement differs from revocation; no successor freshness (C2) |
| Policy/manifest/quarantine | No unsafe admission (C6) |
| Frozen records, mutable aliases, subclasses, invalid construction | Deep-safe descriptive inputs |

These are new pure-stage controls, not completion of the frozen 45 author matrix
cases or closure of prior BLOCK findings. Original evidence remains immutable.
