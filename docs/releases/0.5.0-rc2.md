**Wisp 0.5.0-rc2** is the next tester build of 0.5.0. It builds on [rc1](0.5.0-rc1.md), and everything those notes say still applies unless it's listed here. The chat model is the same untuned Gemma 4 E4B (`gemma-4-E4B-it-oQ4e-mtp`) as rc1. It also carries the fixes from a full review of the code. The built-in engine is now oMLX 0.7.3.

## What's new

### Meeting notes, in a new Meet tab

- **Press Start a meeting** in the notch's fourth tab (⌘4), and Wisp listens through the microphone. The words appear as it goes, written down by your Ask model on this Mac about every 25 seconds.
- **When you stop,** the same model writes a short summary, the decisions, the action items (with who and by when, if someone said so) and a follow-up message you can copy.
- **Remind me** on an action item adds it to Reminders for the date that was said, or for tomorrow. Nothing is added until you press it.
- **No audio is kept.** Only the text is saved, on this Mac, and nothing leaves it. Earlier meetings stay in the tab and can be deleted there.
- **The other side of a call.** With Screen Recording allowed for Wisp, a meeting also hears the sound your Mac plays, so a call is heard even with headphones on. Only sound is taken, macOS shows its screen-recording indicator while it runs, and the tab says what it is hearing.
- **What is said is treated like any outside text.** Nothing said in a meeting is acted on.

### Reply drafts in your own writing style

- **Settings > Privacy has "Write reply drafts in my style".** Press Learn my writing style, and Wisp reads the emails you sent from Apple Mail and trains a small add-on for your chat model, on this Mac.
- **It's used for one job only:** the reply drafts the Brief writes for you to edit and send yourself. Ask and everything else keep the usual model, and the add-on never runs a tool.
- **Only your own words are learned.** The training text is deleted when the run ends. What stays is the add-on, about 14 MB. Forget in the same row erases it, and so do "Forget what Wisp learned from mail…" and `/resetwisp`.

### Smoother notch

- **Moving around the notch is smooth.** Switching between Ask, Brief, Day and Meet, and opening Settings or a permission page, now moves on one calm spring. The panel grows and shrinks with its content instead of snapping, the tab highlight slides, and each tab remembers where you were scrolled. With Reduce Motion on, pages switch instantly as before.
- **Answers read in a serif typeface.** Code, tables and buttons are unchanged.
- **Start over for a stuck permission.** If Screen Recording or Accessibility says "Not allowed" in Wisp while System Settings shows Wisp switched on, the permission page now has a Start over button. It makes macOS forget that one answer for Wisp, so it can ask again.

### Ask reads the files attached to your emails

- **Ask about an attachment.** Ask things like "what's in the PDF John emailed me" or "what's the total on the invoice she sent". Wisp reads pictures, spreadsheets, PDFs and documents attached to your emails, several emails at once. It uses Apple Mail's saved copy first and Gmail for anything that isn't on this Mac.
- **It reads only when you ask,** and only with this Mac's own model.
- **Programs, scripts and archives are described, never run or unpacked.** Each reading says how much of the file it covered.
- **What a file says is treated like any outside text.** After Wisp reads an attachment, everything else it would do in that chat asks you first, with no Always allow.
- **Emails show their files.** An email Wisp reads starts with a line naming what's attached.

### Big pictures and long files

- **Large pictures stay sharp.** A big picture, such as a screenshot of a large screen, is read as an overview plus sections, so small text is no longer lost when the picture is shrunk.
- **Long documents aren't cut off at the start.** A long file is searched or condensed section by section, and each reading says how much of it was covered.

### 16 GB of memory

- **16 GB is now the stated requirement,** with no separate 24 GB recommendation. Wisp's memory use and the way it loads Gemma are the same as in rc1.

### Safety, privacy and settings

- **Turn off learning from your mail.** Settings > Privacy & Access has a "Learn facts about me from mail" switch and a "Forget what Wisp learned from mail…" button. Forgetting asks first, also erases the text Wisp kept from attachments it read, and turns the switch off.
- **See and remove your Always allow rules.** Settings lists every rule you made with Always allow on a card, with what it covers and a Remove button. After you remove one, Wisp asks about that action again.
- **Opening a different copy of Wisp asks which one to use.** If an older Wisp is running, Wisp names both versions and lets you quit the running one and open the new one, or keep the running one.
- **Cards say what Always allow covers,** and Disconnect & erase in Settings > Google asks first, naming the account and what will be deleted.
- **Very dangerous commands are refused outright,** in every mode including Full access: deleting whole folders by absolute or home path, erasing disks, changing permissions across the system, running code straight from a download, and turning off macOS protections. Wisp says it won't run them and that you can run them yourself in Terminal. Deleting a build folder inside a project still asks with a card, and so does one plain delete of a full path in an ordinary folder, such as `rm -rf /tmp/build`.
- **Human-sounding replies is for messages you send.** It now shapes the emails, texts and replies Wisp writes for you, and no longer changes Wisp's own answers.
- **Missed alarms stay quiet.** A timer or alarm the Mac slept through no longer rings when it wakes, unless it is less than 5 minutes late. A daily alarm waits for its next time.
- **Old "Always allow" rules for moving files ask again.** A rule saved before this build no longer covers every move. Your next answer saves a rule for that folder only.
- **Deleting a folder with spaces in its path asks first.** A quoted path, such as a folder inside `~/Library/Application Support`, now gets a card that shows the exact paths and says when one is a link. Wisp checks the paths again just before the delete runs and stops if a link has changed. A name made to look like a protected folder is refused.
- **A delete by full path always asks,** even under Full access or with your own rule list changed.

## Fixes

### Ask understands more of what you say

- A long pasted text no longer ends in "Something went wrong". If it really is too long, Wisp says so and asks for smaller parts.
- If one of several calendar events has a time Wisp can't use, the others still get their card.
- "When is my meeting with Sam?" reads your calendar, and "When is the next lunar eclipse?" can search the web.
- "Don't change anything" now holds for the whole request, and "Don’t use my memory" works with a curly apostrophe.
- "Do it" and "how about 6pm" now act on what Wisp just offered.
- "Update my dentist appointment to 4pm", "let my mom know I'm running late" and "take the dentist off my calendar" are no longer refused. Each still asks before anything changes.
- A question asked together with a reminder gets its answer after the reminder receipt.
- Correct answers such as "You have 64% battery left" are no longer replaced with "I don't have that."
- "What are Costco's hours?" can search the web on the first message of a chat. Wisp only searches, using the words you typed: it won't open pages on that message, and it won't search when the name is a phone number, a street address, or matches someone in your profile or the contacts Wisp has already loaded.
- "When is the next meeting?" and "When is the party on Saturday?" read your calendar and reminders.

### Times, timers and reminders

- Timers, alarms and sleep timers now ring on time, and they survive a restart. One the Mac slept through rings when it wakes only if it is less than 5 minutes late (1 minute for a sleep timer).
- "Five minutes", "an hour and a half" and "half an hour" set a timer.
- "Tomorrow morning at 7" means 7 AM, "tomorrow at noon" means 12 PM, and "Remind me Friday evening" keeps Friday.
- You can mark a reminder done after its time has passed, and cancel a reminder or event more than 60 days away.
- A reminder that came due while the Mac was asleep alerts when it wakes, and reminders show while a Wisp window is in front.
- A scheduled email or text that came due while Wisp was closed is sent when you open Wisp within 30 minutes. One scheduled before you switched to View-only is not sent.
- "Text mom in two hours that I landed" and "email Bob at five" are scheduled instead of sent right away.

### Mail, texts and sending

- Cards and receipts name the contact a message really goes to. Two contacts with the same name are told apart by their last four digits and Wisp asks which one you mean.
- The forward card shows the email's subject, sender and date.
- An approved email is sent exactly as its card showed it.
- Wisp no longer says an email was sent when Mail refused it, and a send that macOS blocks says how to fix it in System Settings > Privacy & Security > Automation.
- Reply cards say in plain words why a reply wasn't sent, show every recipient, and don't say "timed out" while the reply can still go out.
- Archive, mark as read and flag work on your emails again.
- A reply you send from an iCloud, Outlook or Exchange account now clears its suggestion.
- Mail from friends with non-Latin names is no longer filed as a newsletter, and people named Gruber, Chapple or Huber are no longer treated as automated senders.
- An expired Google sign-in is no longer retried every minute, and Wisp says when the Gmail API is turned off in your own Google Cloud project.
- Apple Mail's Sent folder is found when the account names it in another language.
- A text approved on a card always goes to the number the card showed. A number supplied any other way is refused.
- Wisp catches a message or email to a contact whose saved address is your own.

### Attachments and files

- Text in spreadsheet cells with line breaks stays in one row, and tables on PowerPoint slides are read.
- A password-protected Word, Excel or PowerPoint file is called password-protected.
- Text and CSV attachments that happen to begin with "MZ" or "BM" are read.
- A short scanned PDF with a blank page is no longer called too long to open.
- Wisp no longer says its app isn't connected during a short reconnect.
- Reading a huge file or listing a huge folder no longer strains your Mac, and folders macOS is blocking point you to Full Disk Access.

### Web and research

- Research no longer stops when two results are the same page.
- Short answers such as a crypto price come back instead of failing.
- Stock prices are for the company you named.
- Wisp says when a page is an old Internet Archive copy, and gives the day it was saved.
- Web fetches refuse addresses on your own network, and a page is shown under the address it really came from.
- A web page can no longer read your chats through a DNS trick.

### Privacy and memory

- Forgotten memories and deleted chats are overwritten in Wisp's files, not only hidden.
- Asking Wisp to forget something also removes it from the debug export.
- A long pasted message no longer shows up as a failed memory job.
- Attachment text is erased whenever its Mail account is removed, and Disconnect & erase also removes the saved Daily Summary.
- Links in answers open web pages only, and links hidden in email subjects show as plain text.
- Wisp asks before opening Terminal or Shortcuts however the app is named.
- Chats deleted in earlier builds are cleared from Wisp's chat file and its search too. The file is rebuilt once, in the background, the first time this build starts.
- Wisp refuses a find-and-delete whose only filter is negated, and a shell whose program comes from another command's output. A shell that only takes an argument from another command asks first in every mode.
- A dangerous command written with a quoted bracket as an extra word is refused like the plain form. In earlier builds the bracket hid the rest of the command from the check, so it got a card or, under Full access, ran.
- A commit message or a note written to a text file in your home folder is no longer refused because it mentions a dangerous command. The file must be a real file, not a link.

### App, setup and the notch

- A crash or Force Quit no longer blocks the next launch.
- Quitting Wisp no longer leaves the Mac's GPU power cap on, and a leftover engine from a crashed Wisp is stopped at the next launch.
- Closing the notch no longer cuts off a reply that is still being written in the Wisp window or on your phone.
- The notch keeps opening and closing after a display change, and VoiceOver says when Wisp needs your approval.
- Setup says why Wisp failed to start, no longer calls the model ready when its test failed, and no longer shows "Wisp isn't set up yet" at every launch.
- Text size now reaches the evening check-in, nudges, setup card, Research and the Brief's reply box.
- Switching to dark or light mode works again, and Wisp no longer says Bluetooth changed when it did not.
- The Wisp window keeps what you were typing and says why a message came back.
- Notes with Chinese, Japanese, Korean or emoji text no longer crash Wisp, and Smart Search no longer freezes Wisp on a large page.
- A meeting with no title shows on Day as (untitled), and a reminder with a date and no time reads "All day".
- The built-in engine no longer refuses to load or answer for up to 30 seconds after the Mac wakes.
- The summary Wisp writes after a turn uses only a model that is already loaded, so it doesn't unload a different one.
- The hours step of Getting to know you, the report draft card and Smart Search follow the Text size setting.
- In Settings, an old rule for moving files reads "No longer used · Wisp asks again for moves".

## Known issues

- **Meet hasn't been tried with a real meeting yet.**
  - It doesn't say who said what, and it stops listening after three hours.
  - On speakers, a call may be heard twice, through the microphone and directly; this hasn't been tried with a real call.
  - The microphone must already be allowed (press the mic in Ask once).
  - While a meeting is being written down, Ask may answer more slowly, because both use the same model. If the model was busy and part of a meeting wasn't heard, the notes say how much was missed.
- **Writing-style replies haven't been tried on real sent mail yet.**
  - It needs the oMLX app installed, because its Python does the training, and it reads Apple Mail only, not Gmail.
  - It needs at least 12 sent emails, and with only a few it copies their phrases more than it learns a style.
  - An add-on can repeat things you wrote before, so read each draft.
  - Training pauses while Wisp is answering you, but uses about 6 GB of memory. On a 16 GB Mac, start it when you aren't using other heavy apps.
  - It is tied to the chat model it learned with, and must be learned again if that changes.
- **Screen Recording and Accessibility may need Start over after an update.** macOS saves these two answers for one exact copy of Wisp, so a new build can show "Not allowed" until you press Start over and allow it again.
- Reading an attachment from Gmail hasn't been tested yet on a real Google account. Apple Mail's saved copies have been.
- The Swift app changes in this build were compile-checked and tested by automated checks, but not all of them were checked by hand on a real Mac. Still to hand-check: the dark-mode switch, the Bluetooth on/off read-back, and read-aloud.
- Chats deleted in earlier builds are cleared from Wisp's chat file the first time this build starts. Copies outside that file, such as Time Machine backups and disk snapshots, are not touched.
- "What are Costco's hours?" now searches the web, but other wordings such as "Is Costco open on Sunday?" may still get no search on the first message of a chat. "Search the web for …" always searches.
- Deleting a folder by its full path is refused, not asked about, when the command does anything besides that one delete. You can run it yourself in Terminal.
- A commit message or a note written to a text file may now mention a dangerous command. Other commands whose text only mentions one, such as a search for it, are still refused.
- Forwarding an email through Apple Mail still stops with "Forward outcome unknown, check Mail" rather than sending, because that step hasn't been checked against a real forward yet.
- "Human-sounding replies" now applies only to messages Wisp writes for you to send. It hasn't been checked with the real model yet, so on a turn where Wisp writes a message, some of that style may still show in its own answer.
- rc1's known issues still apply, except that Ask's own "forget" now clears the debug export and a reply sent from a non-Google account now clears its suggestion.
- A version of Gemma 4 E4B fine-tuned for Wisp is still in development. This release ships the untuned model; the tuned one replaces it only after it matches or beats the current model on every test.
